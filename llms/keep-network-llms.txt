# Keep Network

> Keep Network is a privacy-focused blockchain infrastructure project that merged with NuCypher to form the Threshold Network. Its flagship product is tBTC, a decentralized, trust-minimized bridge that tokenizes Bitcoin (as the TBTC ERC-20 token) for use in Ethereum DeFi without centralized custodians. The developer surface is on-chain smart contracts plus first-party JavaScript/TypeScript libraries — there is no hosted REST API.
